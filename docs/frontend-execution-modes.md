# 云端与本机处理：前端交接（2026-11-01）

本轮对应 baseline M1 的界面完善和 L1 的准备说明。默认展示云端处理，可选择本机处理；开发环境另有明确的模拟联调入口。改动仅保存在本地，未自动推送。

## 当前界面行为

- 云端：显示素材上传、远程 GPU 分析、预览与下载的路径。当前没有已接入的云端服务，提交按钮禁用；选定素材仅在浏览器本地预览。
- 本机：展示设备检查、模型/权重准备和持久缓存流程。模型发布包、文件大小、硬件要求、许可与下载/缓存 API 均未提供，所以下载按钮保持禁用，不显示虚构进度或设备信息。
- 只有当前页面连接 localhost 且 `/api/v1/model` 返回 `mock=false, available=true`、`/ready` 返回 `ready=true` 时，本机处理才能提交。这表示已有模型服务报告就绪，不代表前端检测了用户的独立显卡或验证了真实模型效果。
- Mock 服务通过“进入本机模拟联调”显式使用，仍运行现有 uploads/tasks/preview/exports v1。
- 任务创建后锁定运行方式；任务记录和待确认请求记录运行方式，刷新恢复不会把模拟任务显示为云端任务。
- 模式选择不添加 v1 Schema 未声明的字段，也不暗中更改服务地址。浏览器不保存 SSH 主机凭据或私钥。

## 云端算力后续工作

浏览器通过 HTTPS 上传到产品 API。业务后端保存受控文件、创建持久任务并交由 GPU worker；worker 可以位于云服务器或经授权的团队独显电脑。若采用 SSH/SFTP 传输，由后端维护连接、验证主机密钥、传输素材并校验完整性，再触发推理、获取结果和渲染产物；普通浏览器不能直接 SSH 到 GPU 主机。

远程视频传输成功不等于剪辑完成。还需要真实 runner、任务与模型版本固定、排队/失败/超时恢复、输出格式校验、媒体预览和导出、文件访问隔离与清理机制。远程主机地址、访问权限、算力配置和部署方式尚待实际提供。

需要先评审扩展契约：可用算力/执行位置及就绪状态、任务绑定的 worker、远程传输/推理阶段和失败原因。现有 v1 tasks 只有 queued/running/终态，前端不能自行伪造 SFTP 进度，不能往严格请求体里添加 host、SSH 参数或 execution_mode。

## 模型下载后续工作

需要固定版本的模型发布清单（文件及 SHA256、大小、环境与硬件要求、许可）、本机环境检测、用户确认下载/离线导入、本机下载进度、断点恢复、完整性校验、缓存加载与版本更新/回退接口。只下载权重不能代替 Python/CUDA 等运行环境准备。上述接口完成并验收后再启用下载入口。

## 验证

`node --check apps/frontend/app.js` 与 `node tests/frontend.cjs`。浏览器覆盖默认云端状态、云端/本机未就绪时禁止传输、模拟联调、任务模式锁定、模式恢复和已有编辑/导出流程。本机真实服务就绪的 UI 使用明确接口夹具验证，不作为真实 GPU 验收。
