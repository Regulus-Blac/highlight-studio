# 云端与本机处理：前端交接

更新：2026-11-25。当前页面和SSH演示入口均已合入产品代码，不再是“仅本地未推送”的修改。课堂范围见[最终改进计划](FINAL_IMPROVEMENTS_PLAN_20261125.md)，启动见[演示手册](demo-runbook.md)。

## 当前实际行为

| 启动/连接方式 | 页面判断 | 可以执行什么 |
|---|---|---|
| 本机默认Mock | model.mock=true；没有远程deployment | 显式选择本机模拟联调，空预测，无成片 |
| 本机mock-media | 合成引擎、mock=true | 上传、片段调整、预览、MP4/JSONL，始终模拟标记 |
| 本机手工配置command | model.mock=false、available=true且ready=true | 本机真实模型分析；不代表网页已检测显卡或自动装好模型 |
| connect_demo.py --mode real | 可选deployment声明remote/real，model与ready匹配 | 本机网页连接已有远程F1，上传后由远端处理 |
| connect_demo.py --mode mock | remote/mock，与合成引擎匹配 | 远程模拟流程，不能冒充真实分析 |
| Start-Demo / start_demo.py | remote/real 描述目标；connection 描述连接；local_demo=true | 远程失败仍打开本机网页，云端置灰，本机模拟使用独立数据与 `/demo/` 同源通道 |
| 普通本机服务的云端选项 | 没有对应远程部署信息 | 仍禁用，不能说已提供通用云产品 |

任务创建后锁定执行位置，模拟与真实远程记录分开存储，刷新恢复向原服务查询。预测请求不增加host、SSH参数或execution_mode等未声明字段；主机凭据只由本机连接器交互获取，不进入浏览器。

2026-11-27：保存配置的统一启动器在空工作区、远程未就绪时默认进入有明确标记的本机演示；已有真实任务继续保留原执行位置并报告断线，不静默替换结果。远端恢复后可在新工作区选择云端，本机演示仍可选择。重连按钮重新读取本机保存配置，不接受网页提交主机或凭据。完整机制与验证见[离线启动初稿](changes/2026-11-27-offline-startup.md)。

## 当前仍缺的能力

没有公网通用业务入口、跨主机worker调度、浏览器模型下载/导入、设备检测或缓存管理。现有下载按钮保持不可用；本轮由D收敛这些未完成入口，B做启动与环境检查，E/A协助状态/媒体语义，不扩展完整安装器或账户体系。

## 前后端协作

复用/api/v1/model、/ready和连接器提供的可选/api/v1/deployment。普通服务deployment返回404时仍按本机处理，不伪造远程状态。页面在断连、GPU未开、模型未就绪时给下一步，不静默切Mock；没有细粒度真实推理百分比就展示等待/阶段。

一条SSH连接串行转发请求，仅适合受控课程演示；演示者启动后观众只用网页。新机器仍需实际GPU环境、权重与部署脚本，详见F1文档。

## 验证边界

已有JS语法、前端资源HTTP、浏览器夹具及SSH二进制/Range测试。界面夹具不能代替真实GPU、视频成片或远端在线检查。本轮修改模式入口后由D复跑相关检查，由B提供真实连接条件，由A记录有限新样片验收。
