## 项目定位

大学生软件工程示例：单个受信任操作者通过浏览器完成“上传一个视频 → 分析 → 检查/调整片段 → 预览 → 下载MP4或JSONL”。团队维护一台GPU主机即可；ABDE四人都投入产品改进，A/B本阶段不再训练模型。账号计费、多租户、分布式调度、对象存储和专业剪辑功能不作为课程交付条件。

## 两条可用启动路径

### 普通电脑：完整流程模拟

Python 3.11+，FFmpeg/FFprobe 6.1+可在PATH找到（也支持`FFMPEG_BIN`/`FFPROBE_BIN`）。普通克隆即可，不需要私有比赛子模块、GPU或模型权重。

```sh
python -m pip install -r requirements-dev.txt
python -m apps.backend.server --port 8001 --runtime runtime/local-demo --adapter mock-media --allow-mock-media
```

打开`http://127.0.0.1:8001`，选择“体验演示模式”。`python scripts/create_demo_video.py`可生成合成流程样片；它用于媒体验证，不代表AI效果。默认不带adapter参数启动的是空Mock，不能据此演示高光成片。

### 真实效果：连接已有GPU部署

演示者先在平台开启已部署的GPU实例，再在本机运行：

```sh
python -m pip install -r requirements-demo.txt
python scripts/connect_demo.py --host <SSH主机> --user <SSH用户名> --ssh-port 2020 --instance 0 --remote-root /root/sj-fs/highlight-studio/f1/candidate-v0 --mode real
```

按提示认证，保持终端开启，访问`http://127.0.0.1:18000`。连接器会启动已有远程服务，不负责给空服务器安装模型，也不自动开通GPU；机器路径按实际部署调整。无`/usr/bin/python3`的主机使用`--remote-python`。详细准备与恢复见[演示手册](demo-runbook.md)。

当前远端所需的`mock-service.sh`、`sj-f1-service.sh`、资产布局及验收目录属于部署环境，不是一次Git克隆就具备的文件。新机器需按[F1部署说明](f1-video-inference.md)准备；普通观众只操作网页，不需要获得主机凭据。

## 素材与性能边界

- 默认上传上限512 MiB；媒体校验上限10分钟、4K像素、120fps、72000帧，单视频流、方形像素、无旋转，音视频起始时钟为零。2026-11-26 本 PR 撤销 CFR 硬性准入限制；VFR 暂用平均帧率时钟，音画同步和真实时间戳映射暂缓，旋转等其余检查保留。
- 演示优先选有权使用的10～30秒H.264 CFR MP4，音轨AAC或无音轨。上述校验上限不代表长视频已充分压测。
- 既有12秒样片：4090独立预测86～87秒，4090D为71～74秒；显存采样峰值约19.2GB。两种画幅均有真实推理/音频导出记录，不能外推所有视频或承诺实时。
- 真实空预测是合法结果，可导出空JSONL，不生成空MP4。模拟、真实结果与失败状态均需保留真实标记。
