# 02 功能与交互需求（初稿）

[返回需求文档导航](README.md) · [上一篇：产品范围](01-product-scope.md) · [下一篇：系统模型](03-system-models.md)

## 1. 页面结构

首版建议采用三个主要页面，任务状态嵌入项目，避免建立复杂后台。

| 页面 | 核心内容 | 主要操作 | 必须覆盖的状态 |
|---|---|---|---|
| 项目列表 | 项目名称、源视频缩略图、最近任务状态、更新时间 | 新建、打开、删除 | 首次使用、加载中、无项目、读取失败 |
| 新建与上传 | 名称、格式限制、文件、上传进度、素材元数据 | 上传、选择画幅、开始分析 | 未选择、上传中、校验中、无效素材、模型不可用 |
| 剪辑工作台 | 源视频/裁剪预览、高光片段列表、时间边界、保存状态、导出记录 | 预览、启用/删除、调整、保存、恢复、导出、下载 | 排队、分析、无高光、可编辑、未保存、导出中、失败、完成 |

工作台建议采用“左侧片段列表、中间播放器、右侧片段设置、底部操作区”。播放器显示源视频时间；成片预览明确显示成片时间，避免混淆。布局是设计建议，不是像素级界面规范。

## 3. 详细需求

### FR-01 创建项目

- 用户输入名称；初稿建议长度 1～80 个字符，去除首尾空白后不得为空。
- 后端生成不可由名称推导的 `project_id`，名称相同不构成同一项目。
- 一项目只绑定一个成功入库的源视频。换视频应新建项目，防止旧帧号、裁剪和导出被错误复用。
- 创建失败不显示成功卡片；成功后刷新可查询项目。
- **验收依据：**AT-01、AT-13。

### FR-02 上传与校验视频

- 页面在选择前显示 [媒体限制 A-03～A-05](01-product-scope.md)，上传中显示实际字节进度；上传完成与媒体校验完成分别展示。
- 后端检查实际内容、容器、编码、时长、帧率、尺寸、旋转、可解码性及有无音轨，不能仅检查扩展名或浏览器提交的类型。
- 临时文件完成校验后才成为可分析素材；失败文件不得出现在模型任务输入中，临时文件应清理。
- 用户只能提交文件，不能填写服务器路径。内部生成存储标识，原文件名只用于显示。
- 源视频保留原字节及摘要；首次范围不支持的变帧率、旋转或超限输入明确拒绝，不能悄悄转码后继续套用原帧号。
- 上传断开后可重新上传；首版不要求断点续传。重复提交不能覆盖一个已经入库的素材。
- **验收依据：**AT-01、AT-02、AT-03。

### FR-03 配置并提交真实分析

- 必须有有效素材，且所选比例在当前部署已验收的能力列表内。
- 提交后快速返回任务编号与 `queued` 状态；任务开始执行后转为 `running`。接口不等待 GPU 推理完成才返回。
- 同一项目存在活跃分析时，不得再创建第二个分析任务；重复点击使用同一幂等键获得原任务。
- 每次分析绑定源文件摘要、比赛提交、模型资产版本、适配器版本和实际配置，界面可以查看简洁的模型版本说明。
- 模型暂不可用时提供明确提示；不得自动以模拟结果替代真实分析。
- 再次分析生成新任务和新结果；已有剪辑方案、旧分析与已导出文件不被覆盖。首次有效结果可建立初始方案；已有方案时，采用新结果需用户明确选择。
- **验收依据：**AT-04、AT-05、AT-12。

### FR-04 查询任务状态与错误

- 显示四种持久化状态：`queued`（排队）、`running`（执行）、`succeeded`（成功）、`failed`（失败）。
- 阶段单独记录，例如校验、提取特征、模型预测、校验结果、渲染、检查成片；阶段不是额外终态。
- 仅在执行端能提供真实计数时展示百分比；否则显示阶段与已用时间，不伪造匀速进度或剩余时间。
- 刷新、关闭或切换页面不取消任务。页面恢复后读取同一个任务。
- 错误展示简明原因、是否可重试及建议操作；诊断编号用于定位日志，用户界面不展示机器路径或完整堆栈。
- **验收依据：**AT-05、AT-13、AT-14、AT-16。

### FR-05 呈现高光建议

- 结果必须通过视频身份、帧号排序/唯一性、数值有限性、裁剪范围和目标比例检查；失败进入任务失败状态。
- 按连续原视频帧划分初始片段，保留真实空隙；不能把第一帧到最后一帧之间的全部内容当成一个高光。
- 每段显示起止时间、时长与定位入口；点击后从该段起点预览，播放到片段终点停止或按明确选择切到下一段。
- 不显示模型没有提供或未经校准的“置信度”“精彩程度百分比”。
- 合法空结果显示“分析完成，未发现建议片段”，允许查看源片、返回或再次分析，禁用导出。
- 极短片段仍保留，可提示时长较短；不得为改善外观而无提示丢弃单帧建议。
- **验收依据：**AT-06、AT-07、AT-08。

### FR-06 选择保留片段

- 用户可启用/取消片段；列表中的“删除片段”只改变剪辑方案，不删除源视频或模型结果。
- 启用片段按源视频时间顺序排列；首版不提供拖拽重排。
- 实时显示启用片段数量及预计总时长。全部取消时仍可保存，但不可导出，并说明需要保留至少一段。
- 取消后可重新启用；恢复原建议时重新启用原始建议片段。
- **验收依据：**AT-09、AT-10。

### FR-07 微调片段边界

- 允许调整启用片段的开始和结束，可用时间输入与逐帧微调；显示结果必须落在源视频帧边界上。
- 以原帧区间 `[start_frame, end_frame_exclusive)` 保存；开始小于结束，且范围不超过源视频帧数。
- 两个启用片段不得重叠；相邻片段允许存在。非法输入保留编辑内容并提示冲突，不能悄悄截断、交换边界或重复输出同一帧。
- 扩展到模型没有选中的帧时，使用该片段原建议边界的最近有效裁剪框；提示“新增范围沿用边界裁剪”，不将此描述为新增 AI 判断。详细规则见 BR-05。
- 时间边界修改不重新调用模型。切换目标比例需要新的分析，不能直接将旧框换一个比例解释。
- **验收依据：**AT-09、AT-10、AT-11。

### FR-08 自动裁剪与预览

- 支持查看原画面裁剪框叠加和裁剪后的画面，明确标记预览模式与当前片段。
- 框采用源像素坐标，播放器缩放或留白后的显示坐标必须正确映射；不能把屏幕坐标写回模型结果。
- 自动模式按模型每帧预测执行。模型框宽度变化时，裁剪后缩放到本次导出固定分辨率。
- 预览与导出使用同一套帧选择、裁剪边界、边界扩展和尺寸对齐规则；以实际导出成片的播放作为最终确认。
- 预览失败不能把黑屏或空框当作成功；应允许回看源片并提示失败。
- **验收依据：**AT-08、AT-11、AT-18。

### FR-09 保存与恢复剪辑方案

- 显式区分“有未保存修改”“保存中”“已保存”“保存失败”。保存成功才更新版本号与时间。
- 保存包含基于哪份分析结果、启用片段、原帧区间和裁剪模式；模型原始建议保持不可变。
- 保存采用版本检查。两页同时修改同一项目时，较旧版本提交返回冲突，不能覆盖较新内容。
- “恢复原建议”表示以当前方案绑定的分析结果重建草稿；有修改时说明影响并要求用户确认，确认后仍需保存。它不删除已有导出记录。
- 有未保存修改时离开页面应提示。导出只接受明确保存的版本；不能悄悄导出旧版本。
- **验收依据：**AT-10、AT-12、AT-13。

### FR-10 生成成片

- 导出前验证：真实分析成功、`mock=false`、素材可用、已保存版本一致、至少一个合法启用片段。
- 导出任务绑定不可变的剪辑版本及输出配置；渲染过程中再编辑不会改变当前导出的内容。
- 输出为 MP4，初稿目标为 H.264 视频、存在原声时采用 AAC 音频；不添加音乐、字幕、水印或转场。
- 输出比例正确，所有片段统一尺寸和帧率；首版建议不放大源裁剪区域，具体编码尺寸由固定渲染规则计算并记录。
- 有原声时按同一时间范围裁剪并拼接；无音轨时输出可正常播放的无声视频，不把缺音轨当作失败。
- 写入临时文件并校验可解码性、尺寸、时长、音轨后，才发布为可下载文件并标记成功。
- 同一项目一次最多一个活跃导出任务；资源不足或失败不影响已有成片和保存方案。
- **验收依据：**AT-11、AT-12、AT-14、AT-18。

### FR-11 预览并下载成片

- 仅成功导出提供成片预览和下载；显示成片时长、画幅、编辑版本、生成时间与文件大小。
- 下载通过受控的导出编号定位文件；支持播放器需要的分段读取，不暴露任意文件读取入口。
- 多次下载不重新推理或渲染。下载失败可重新发起下载，不改变导出状态。
- 文件缺失应显示“文件不可用”，不能只根据旧数据库状态返回损坏文件或成功提示。
- **验收依据：**AT-11、AT-15、AT-18。

### FR-12 查看历史并继续编辑

- 列表显示项目名称、更新时间、最新分析/导出状态，并可打开项目。
- 刷新或服务重启后保留源素材信息、分析结果、已保存编辑版本及导出记录。
- 正在运行的任务如何恢复按 FR-13 处理，不能一律显示“仍在处理中”。
- 首版历史仅要求项目/任务/导出记录和当前保存方案；不要求实现可视化任意版本回滚。
- **验收依据：**AT-13、AT-14。

### FR-13 处理失败与重新执行

- 输入无效、模型不可用、显存不足、超时、结果非法、磁盘不足、渲染失败分别有可识别的错误码。
- 进程重启后，在确认旧执行进程已结束的条件下，将遗留 `running` 任务记为失败并释放占用；未开始的 `queued` 任务校验依赖后恢复排队。
- 采用有限超时和单执行者领取，避免两个进程同时处理同一任务；具体超时须由设备实测确定。
- 手动重试创建新任务，记录 `retry_of`；旧任务与错误记录保持。首版不自动无限重试或自动降级到另一模型。
- 导出失败优先重用已保存分析与剪辑方案，只重新渲染；不重复消耗模型推理资源。
- **验收依据：**AT-05、AT-14、AT-16。

### FR-14 删除项目与清理文件

- 删除前告知将移除源视频、分析结果、编辑方案和成片，并由用户确认。
- 有活跃任务时拒绝删除并说明原因；首版不通过删除隐式中止 GPU 作业。
- 无活跃任务时先将项目标记为删除处理中，禁止创建新任务或下载，再清理仅属于该项目的文件。
- 清理完成才确认删除成功。中断或权限错误时保留待清理记录并允许再次执行；不能留下“记录已消失但大文件无人管理”的状态。
- 不删除其他项目、模型资产或比赛目录；共享模型资产不归项目所有。
- **验收依据：**AT-15、AT-17。

### FR-15 编辑增强（P1）

| 增强项 | 最小要求 | 尚未实现时 |
|---|---|---|
| 每段固定裁剪框 | 拖动或输入位置，锁定目标比例，验证边界；覆盖该段全部帧并可恢复自动模式 | 隐藏手动裁剪入口，保留自动预览 |
| 手动新增片段 | 从源视频指定合法范围，配固定合法裁剪框；不虚构模型判断 | 无高光仍按 FR-05 展示空状态 |
| 第二种目标比例 | 在新视频上验证模型和渲染，建立独立分析结果 | 不开放未经验证的选项 |
| 单片段导出 | 沿用同一渲染与版本规则 | 仅提供全部启用片段合并导出 |

P1 的验收另见 AT-19，未实现不影响 P0 完成判断。

## 4. 统一反馈与异常展示

| 情况 | 推荐用户提示 | 可用操作 |
|---|---|---|
| 模型未配置 | 当前部署尚未接入真实模型 | 返回、查看帮助；模拟模式必须明确标识 |
| 无高光 | 分析完成，未发现建议片段 | 看源片、重新分析、返回项目 |
| 分析失败 | 分析未完成：简明原因 | 查看诊断编号、在原因排除后重试 |
| 全部片段被取消 | 请至少保留一个片段后导出 | 重新启用、恢复建议 |
| 版本冲突 | 该项目已在另一页面更新 | 重新加载；保留本页未保存内容供核对 |
| 导出失败 | 成片生成失败，已保存的编辑仍保留 | 重试导出 |
| 磁盘空间不足 | 存储空间不足，暂不能继续 | 删除不需要的项目后重试 |

状态不只靠颜色表示，按钮与文字说明一致；错误不得用成功的空结果掩盖。
