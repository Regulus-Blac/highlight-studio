# A/B CPU 开发分支合并评审

历史评审，记录截至2026-10-27的范围，不是当前缺项清单。2026-11-25现状：网页、固定F1新视频runner、GPU双画幅与成片和SSH演示随后均已提供；业务v2/安装器仍未实现且本轮推迟。当前改进按[四人计划](../FINAL_IMPROVEMENTS_PLAN_20261125.md)。

评审范围：`feat/ab-cpu-preparation` 原提交 `6374542` 相对 `main` 的 `bfa0942`，以及本次评审修复。目标是将接口、CPU 媒体处理核心和开发文档交付为 ABDE 的共同开发基线。

## 发现与修复

| 问题 | 复现与影响 | 处理 |
|---|---|---|
| 显式 `segments: null` 被视为默认方案 | POST 编辑预览返回 200，创建导出返回 202；与 Schema 要求数组不符，可能导出用户未明确选择的方案 | 两处入口拒绝非法类型，返回 422/invalid_segments；省略导出字段仍使用原建议，空数组仍表示空方案 |
| 输出目录创建/临时文件清理失败可中断 worker | 用同名文件阻挡导出目录，FileExistsError 在错误处理外抛出，任务停留 running，后续任务无法继续 | 目录创建纳入失败处理，清理异常只写私有日志；当前任务转 failed/render_failed，后续任务继续执行 |

两项均先新增测试复现原失败，再修复实现。原 v1 字段和成功语义保持兼容。

## 合并边界

- 保留远端 main 的需求与 UML 文档；两份用户提供的初稿保持原内容。
- 比赛子模块指针、`.gitmodules`、`model.lock.json` 不变；本次不合并 `sync/competition`。
- Git 仅交付源码、契约、文档和测试；模型、媒体、依赖环境、运行结果仍位于忽略目录或临时目录。
- 本评审当时交付为可联调CPU核心，真实F1资产/recipe/GPU/网页当时待推进；后续完成情况见页首。不可把当时状态当作现在所有功能未完成。

本地仓库引用完整性检查、旧 Mock HTTP 冒烟与完整 CPU 回归均通过；34 项回归包含原 32 项和上述 2 项新增用例。GitHub Actions 的远端状态与本地测试结果分别表述，本次未通过 API 确认远端 CI 状态。
